# ikigai-ledger

**The work ledger for [ikigai](https://github.com/ikigai-rs)**: items, comments, labels,
links and claims as RDF in a durable store — view, query, append, comment, close and
delete as capability-gated resources under `urn:iki:ledger:*`, plus
`urn:iki:ledger:next`, which answers *what should I do next* as a resource with a
pluggable ordering policy.

Scaffold only at this commit; the module lands in the first PR.
