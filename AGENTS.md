# Working in this repository

`ikigai-ledger` is an ikigai module: the work ledger (items, comments, labels, links, claims and
`next`) as RDF in a durable store, served as capability-gated resources. These rules are for
every agent and every person working here. `CLAUDE.md` is a link to this file.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text. Here that is the plain faces (item lines, listings, `next`, write
  answers, the doctor) and every refusal.
- Security reports go through GitHub private vulnerability reporting, never a public issue.
- Every change lands through a pull request with green CI.
- Use American spelling in everything you write: code comments, docs, commit messages and pull
  requests.
